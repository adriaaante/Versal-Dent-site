# Прайс для Яндекс.Бизнеса («Товары и услуги»)

Файл `angel-dent-yandex-business-price.xlsx` — для загрузки в карточку
Яндекс.Бизнеса: раздел **«О компании» → «Товары и услуги» → «Загрузить XLS/YML»**
(перед загрузкой удалить старые позиции).

Генератор `build-price.py` собирает СРАЗУ ДВА файла:
- `angel-dent-yandex-business-price.xlsx` — ручная загрузка (колонки
  **Название · Цена · Категория · Описание**, БЕЗ фото — XLS их не поддерживает);
- `../../yandex-business.yml` (в корне репо, **деплоится**) — YML-фид для
  автозагрузки по ссылке, с ценами И картинками.

## Картинки — только через YML-фид

⚠️ **Ручной XLS-импорт YB НЕ поддерживает колонку с фото** (выдаёт «Неизвестные
поля»). Источник (сайт/Drive/новый) роли не играет — колонку в XLS он не читает.
Поэтому фото подключаются ТОЛЬКО через YML-фид (тег `<picture>`).

- По одной сгенерированной фотографии на категорию:
  `assets/img/yb/yb-<slug>.jpg` (10 шт., 1:1, бренд-гамма; деплоятся).
  Маппинг категория→картинка — `CAT_IMG` в `build-price.py`.
- Фид: `https://versal-dent.ru/yandex-business.yml` (после `~/deploy.sh`).

**Как включить авто-подтягивание в YB:** «Товары и услуги» → «Источник» →
переключить с «Вручную» на загрузку по ссылке → указать URL фида. Дальше YB сам
периодически тянет цены и фото.

> В фид идут только позиции **с ценой** (35 шт.). 5 бесплатных/подарочных/
> скидочных акций (консультация, каждый 3-й имплант, чистка в подарок, −10%,
> семейная) YB из фида с ценой 0 НЕ принимает — их добавляем в отдельный раздел
> **«Акции»** карточки YB вручную.

## Цена

YB **не принимает 0** как цену («ожидается число»). Поэтому у бесплатных и
подарочных позиций (консультация, акции-подарки/скидки) в генераторе цена
ставится **пустой** — смысл передаётся в названии («Бесплатная…», «…в подарок»,
«Скидка…»).

## 🔒 Главное правило: источник цен — САЙТ

**Цены в этом файле ВСЕГДА берутся из сайта, не наоборот.** Сайт — источник
правды. Если цена меняется — сначала правим её на сайте, потом обновляем здесь.

Где лежат актуальные цены на сайте:
- `services/*.html` — прайс-таблицы по каждой услуге (`.prices-table`).
- `promotions.html` — действующие акции (КТ+план, Amazing White, −10%
  пенсионерам, каждый 3-й имплант, чистка в подарок, семейная программа,
  бесплатная консультация ортодонта).

## Как пересобрать файл

1. Свериться с ценами на сайте (см. выше), при необходимости поправить
   список `rows` в `build-price.py`.
2. Запустить: `python3 _materials/yandex-business/build-price.py`
   (соберёт и `.xlsx`, и `yandex-business.yml`).
3. `~/deploy.sh` — чтобы обновлённый фид и картинки уехали на хостинг.
4. YB сам подтянет фид по ссылке (или загрузить `.xlsx` вручную).

## Правила оформления (чтобы не повторять прошлых ошибок)

- Цену **не дублировать** в названии — только в колонке «Цена».
- «от …» и «вместо …» (старая цена акции) — в **описании**.
- Бесплатное/подарочное — цена **пустая** (НЕ `0`: YB его не принимает; и НЕ «1 ₽»).
- **Без просроченных дат** акций (старый список висел «до 31.03.2026»).
- У брекетов **не писать «1 челюсть»** — отпугивает лида (на сайте тоже убрано).

## Почему не деплоится

Папка внутри `_materials/`, которая исключена из `scripts/deploy.sh`
(`--exclude='_materials/'` + `rm -rf`), поэтому на хостинг не попадает —
это внутренний рабочий файл, а не часть сайта.
